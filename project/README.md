# Финален проект

Изберете малък проект, който решава конкретен проблем: анализатор на лични разходи, програма за оценки, викторина, CSV анализатор или клиент на публично API.

## Минимални изисквания

- Ясен `README.md`: какво прави проектът, как се стартира и примерен вход/изход.
- Кодът е разделен на функции с ясни имена.
- Валидиране на входа и обработка на очаквани грешки.
- Поне един файл (CSV или JSON) **или** едно API извикване.
- Поне три `assert`/`pytest` теста за основна логика.
- Git repository с поне три смислени commits.
- `.gitignore`, без пароли, ключове и `.venv/`.

## Предаване

Качете проекта в GitHub и предайте адреса на repository-то. README-то трябва да е достатъчно ясно, за да може друг човек да стартира проекта без допълнителни указания.

## Малка рубрика

| Критерий | Какво се проверява |
|---|---|
| Функционалност | Програмата решава заявения проблем. |
| Качество | Четлив код, функции и обработка на грешки. |
| Проверка | Тестове и разумни гранични случаи. |
| Представяне | README, Git история и лесно стартиране. |

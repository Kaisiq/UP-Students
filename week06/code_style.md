# Стил, имена и docstrings

Четливият код е по-лесен за поправяне и проверка. Използвайте ясни имена и малки функции, които правят едно нещо.

```py
# Неясно
def f(x, y):
    return x * y

# Ясно
def rectangle_area(width, height):
    """Връща лицето на правоъгълник."""
    return width * height
```

## Кратки правила

- Използвайте `snake_case` за променливи и функции: `total_price`.
- Използвайте `PascalCase` за класове: `Student`.
- Константите са с главни букви: `MAX_ATTEMPTS = 3`.
- Един отстъп е четири интервала; не смесвайте табулации и интервали.
- Коментарът обяснява **защо**, а кодът – **какво**.
- `docstring` е първият низ във функция или клас и обяснява предназначението им.

Не повтаряйте код. Ако една и съща логика се появи два пъти, вероятно има място за функция.

## Именуване на променливи

```py
# Валидни имена
myvar = "John"
my_var = "John"
_my_var = "John"
myVar = "John"
MYVAR = "John"
myvar2 = "John"

# Невалидни имена
# 2myvar = "John"
# my-var = "John"
# my var = "John"
```

Променливите могат да съдържат цели числа (`int`), числа с плаваща запетая (`float`), булеви стойности (`bool`) и низове (`str`). По-късно ще разгледаме и списъци, речници, кортежи и множества.

```py
x = str(3)    # '3'
y = int(3)    # 3
z = float(3)  # 3.0
print(type(x))
print(type(y))
print(type(z))
```

## Присвояване и размяна на стойности

```py
x, y, z = 3, 5, 7
print(y)  # 5

x = y = z = 3

a = "a"
b = "b"

# Начин 1
c = a
a = b
b = c

# Начин 2
a, b = b, a
```

## Вход и изход

`input()` винаги връща текст (`str`). Когато е необходимо число, преобразуваме резултата с `int()` или `float()`.

```py
x = input("Enter a number\n")
print(x)

x = input("Enter anything")
print(type(x))  # str

x = int(input("Enter anything"))
print(type(x))  # int
```

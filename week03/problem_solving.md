# Подход към решаването на задачи

Преди да пишете код, направете задачата ясна на хартия или в коментар.

1. **Вход:** какви данни получавам и какъв е техният тип?
2. **Изход:** как точно трябва да изглежда резултатът?
3. **Примери:** проверете поне един нормален и един граничен случай.
4. **План:** опишете стъпките с обикновени думи.
5. **Код:** реализирайте по една стъпка и тествайте.

Пример: „Намери най-голямото число в списък.“

```text
1. Запомни първото число като най-голямо.
2. Обходи останалите числа.
3. Ако текущото е по-голямо, запомни него.
4. Изведи запомненото число.
```

```py
numbers = [4, 1, 9, 3]
largest = numbers[0]

for number in numbers[1:]:
    if number > largest:
        largest = number

print(largest)
```

Мислете и за гранични случаи: празен списък, само едно число, отрицателни числа и повтарящи се стойности. Не започвайте с най-сложния случай.
